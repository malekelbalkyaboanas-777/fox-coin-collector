
# PyGame Zero Mini-Projects 🎮🐍

A collection of beginner-friendly 2D games built using Python and **PyGame Zero** (`pgzero`). These projects were created to master core game development concepts, including event handling, sprite movement, dynamic score tracking, and collision detection.

---

## 🕹️ Included Projects

### 1. Fox Coin Collector 🦊🪙 (`find_character_game.py`)
A fast-paced arcade game where you control a fox to gather coins before time runs out!
- **Features:**
  - Player movement using directional keyboard inputs.
  - Random coin spawn positioning upon collection.
  - On-screen score tracking and a timer-based game-over screen.

### 2. Kick the Apple 🍎 (`little_apple_kick.py`)
An interactive precision game focused on timing and spatial coordinates.
- **Features:**
  - Interactive click and movement mechanics.
  - Real-time score counter and status feedback.
  - Game-over sequence when a target is missed.

---

- **Python 3.x**
- **Pygame Zero** (`pgzero`)
